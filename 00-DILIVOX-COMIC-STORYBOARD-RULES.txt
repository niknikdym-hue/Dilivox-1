СТАТУС: ГЛОБАЛЬНЫЙ КАНОН ПРОИЗВОДСТВА.
Дата фиксации: 1 августа 2026 года.
Применяется ко всем новым и продолжаемым историям-комиксам Dilivox.

============================================================
1. ГЛАВНОЕ ПРАВИЛО
============================================================

ИЗОБРАЖЕНИЕ КАДРА НИКОГДА НЕ СОЗДАЁТСЯ НЕПОСРЕДСТВЕННО ИЗ ЛИТЕРАТУРНОГО ТЕКСТА ИСТОРИИ.

Обязательная производственная цепочка:

1. Сюжет и литературный текст.
2. Карта сцен и драматургических функций.
3. Отдельная производственная раскадровка каждого кадра.
4. Покадровый промпт, составленный только по утверждённой раскадровке.
5. Генерация одного самостоятельного изображения.
6. Самостоятельная визуальная сверка.
7. Утверждение и фиксация файла.

Литературный текст отвечает на вопрос «что происходит в истории».
Раскадровка отвечает на вопрос «что именно видно в одном изображении».
Подменять раскадровку пересказом текста запрещено.

============================================================
2. ОБЯЗАТЕЛЬНЫЕ ПОЛЯ КАЖДОГО КАДРА
============================================================

До генерации для каждого кадра отдельно фиксируются:

— номер и рабочее имя файла;
— драматургическая функция;
— один конкретный визуальный момент;
— тип плана и положение камеры;
— утверждённая локация;
— точный список видимых постоянных персонажей;
— точный список отсутствующих персонажей, которых добавлять нельзя;
— место каждого персонажа в кадре;
— направление корпуса, лица и взгляда;
— конкретное действие каждого видимого героя;
— главный предметный центр;
— обязательный реквизит;
— видимая улика и её сторона;
— источник света и время суток;
— непрерывность с предыдущим кадром;
— элементы, которые должны остаться за пределами изображения;
— жёсткие запреты.

Реплики, подписи и пояснения существуют в HTML и не должны превращаться в текст внутри картинки.

============================================================
3. ОДИН КАДР — ОДИН МОМЕНТ
============================================================

Один кадр показывает одно завершённое визуальное действие.

Запрещено пытаться одновременно показать:
— начало, середину и результат действия;
— несколько разных помещений;
— несколько последовательных событий;
— все подозрения и все улики сразу;
— литературный пересказ целой сцены.

Если один кадр требует объяснения словами «одновременно», «в это же время», «а на заднем плане ещё», необходимо проверить перегрузку и упростить композицию.

============================================================
4. ЛИМИТ ПОСТОЯННЫХ ПЕРСОНАЖЕЙ
============================================================

Рабочая норма для вертикального кадра 4:5:
— оптимально 1–2 узнаваемых постоянных персонажа;
— допустимо 3 постоянных персонажа, если только 1–2 являются смысловым центром;
— 4 постоянных персонажа допускаются лишь для обложки или специально обоснованного ансамблевого кадра с ясной иерархией;
— 5 и более узнаваемых постоянных персонажей в одном сюжетном кадре по умолчанию запрещены.

Анонимные стражники, слуги, прохожие и другие массовочные фигуры допустимы в дальней глубине, если им не требуется сохранять индивидуальную внешность.

Если литературная сцена содержит много героев, она визуально раскладывается на несколько кадров или показывается через главных участников, детали, руки, силуэты и реакцию. Не требуется помещать всех присутствующих в каждое изображение.

============================================================
5. ВВЕДЕНИЕ ПЕРСОНАЖЕЙ
============================================================

Не нужно представлять всех подозреваемых одним групповым портретом.

Персонажи вводятся последовательно:
— через отдельное действие;
— через пару или тройку участников;
— через характерный предмет;
— через узнаваемый силуэт;
— через последующий кадр допроса или проверки версии.

Зритель должен узнавать героя по сцене, а не искать его среди шести одинаково крупных лиц.

============================================================
6. ПРЕДМЕТНЫЕ И МАКРОКАДРЫ
============================================================

Для детективных улик обязательно использовать отдельные крупные планы и макрокадры.

В предметном кадре не требуется показывать всех свидетелей. Допустимы:
— только руки одного героя;
— часть костюма;
— один или два лица по краям;
— утверждённый предмет и точная география объектов.

Это повышает читаемость улики и снижает риск потери идентичности персонажей.

============================================================
7. РАСКАДРОВКА И НЕПРЕРЫВНОСТЬ
============================================================

Каждый кадр обязан продолжать предыдущую визуальную географию:
— положение дверей, окна, камина и стола;
— стороны предметов;
— направление движения;
— состояние одежды и реквизита;
— освещение и время суток;
— появившиеся повреждения и следы.

Ближайший утверждённый кадр используется как якорь непрерывности, но не заменяет раскадровку нового кадра.

Формула:
РАСКАДРОВКА ОПРЕДЕЛЯЕТ НОВЫЙ КАДР.
УТВЕРЖДЁННЫЙ ЯКОРЬ СОХРАНЯЕТ ВИЗУАЛЬНЫЙ МИР.

============================================================
8. ПОКАДРОВЫЙ ПРОМПТ
============================================================

Промпт составляется только после утверждения раскадровки и включает только видимые элементы текущего кадра.

В промпт запрещено переносить:
— полный синопсис истории;
— будущую развязку;
— альтернативные версии;
— служебные объяснения;
— номера, названия и реплики, способные появиться внутри изображения;
— персонажей, которые присутствуют в литературной сцене, но не видны в данном кадре.

============================================================
9. ПАКЕТНАЯ РАБОТА
============================================================

Пакетный режим означает:
— заранее подготовить раскадровки и промпты для блока из 3–4 кадров;
— затем создать отдельный файл для каждого кадра;
— самостоятельно сверить каждый файл;
— не объединять кадры в коллаж или лист.

Перед запуском пакета необходимо проверить, что соседние кадры различаются по плану и действию, но сохраняют единую постановку.

============================================================
10. ЗАПРЕТ НА ГЕНЕРАЦИЮ БЕЗ РАСКАДРОВКИ
============================================================

Если отдельной производственной раскадровки нет, генерация изображений запрещена.

Нельзя считать полноценной раскадровкой:
— общий сюжетный текст;
— литературный сценарий;
— список реплик;
— краткое название кадра;
— общий промпт на всю сцену;
— перечень всех персонажей главы.

Сначала создаётся и проверяется раскадровка. Только после этого начинается визуальное производство.

============================================================
11. КОНТРОЛЬ ПЕРЕД ГЕНЕРАЦИЕЙ
============================================================

[ ] есть отдельная раскадровка текущего кадра;
[ ] показан один конкретный момент;
[ ] постоянных персонажей не больше трёх, если нет специального обоснования;
[ ] определён один главный визуальный центр;
[ ] присутствуют только нужные герои;
[ ] композиция не является групповым портретом;
[ ] улика читается без поясняющего текста;
[ ] утверждены план, камера, свет и география предметов;
[ ] реплики остаются в HTML;
[ ] промпт составлен по раскадровке, а не по полному тексту истории.

При невыполнении любого пункта генерация не запускается.
