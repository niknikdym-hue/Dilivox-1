============================================================

Для каждого кадра генератору передаются фактические PNG только видимых персонажей, локации и предметов текущего кадра.

Запрещено:
— использовать одно имя файла вместо передачи изображения;
— использовать общий лист всей истории;
— использовать ложный аудиторский лист;
— использовать отклонённые кадры;
— передавать референсы отсутствующих персонажей;
— заменять утверждённые лица похожими типажами;
— считать удалённый файл доступным;
— создавать ключевую улику без пригодного предметного PNG.

Технический crop разрешён только из фактического утверждённого PNG и не может изменять лицо, костюм, предмет или сторону улики.
