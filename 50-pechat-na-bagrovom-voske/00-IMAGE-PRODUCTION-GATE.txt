2. ЗАПРЕЩЁННЫЕ СТАРЫЕ МЕТОДЫ
============================================================

Запрещено:
— собирать общий reference sheet из нескольких персонажей;
— создавать производные одиночные «якоря» из уже утверждённых PNG;
— создавать отдельные композиционные макеты перед каждым кадром;
— использовать отклонённые изображения;
— использовать старую композицию кадра 02 с шестью персонажами;
— продолжать изображение от обложки вместо прямого использования утверждённых PNG текущих героев;
— вставлять в запрос номер кадра, название истории, реплики, HTML-текст и служебные пояснения;
— передавать референсы персонажей, которых нет в текущем кадре;
— объединять несколько кадров в одно изображение.

3. ПРЕДПУСКОВОЙ ДОПУСК КАЖДОГО КАДРА
============================================================

Перед запуском проверить:

[ ] выбран один конкретный кадр;
[ ] открыт актуальный блок этого кадра в production-storyboard;
[ ] число узнаваемых постоянных персонажей не превышает трёх;
[ ] выписаны все присутствующие персонажи;
[ ] выписаны все запрещённые персонажи;
[ ] приложены отдельные утверждённые PNG только текущих персонажей;
[ ] приложен утверждённый PNG текущей локации;
[ ] приложены утверждённые PNG только видимого ключевого реквизита;
[ ] действие является одним визуальным моментом;
[ ] главный композиционный центр один;
[ ] правая и левая стороны улик сверены;
[ ] время суток и свет сверены;
[ ] изображение вертикальное 4:5;
[ ] текст внутри изображения запрещён;
[ ] старые REJECT-изображения не используются.

Если хотя бы один пункт не выполнен, запуск запрещён.

============================================================
5. САМОСТОЯТЕЛЬНАЯ ПРОВЕРКА ПОСЛЕ ГЕНЕРАЦИИ
============================================================

Проверка выполняется в следующем порядке:

1. Один самостоятельный вертикальный кадр 4:5.
2. Нет текста, рамки, коллажа, заголовка и номера.
3. Точный состав персонажей; лишних постоянных героев нет.
4. Лица, возраст, волосы, телосложение и костюмы совпадают с утверждёнными PNG.
5. Локация совпадает с утверждённым PNG и эпохой Людовика XIII.
6. В кадре ровно одно утверждённое действие.
7. Главный центр совпадает с раскадровкой.
8. Реквизит совпадает с утверждёнными PNG.
9. Стороны улик соблюдены.
10. Трость соответствует канону и не открыта раньше кадра 21.
11. Нет преждевременного спойлера.
12. Нет анатомических дефектов и дублированных людей.

Любая ошибка в пунктах 1–11 означает REJECT.

8. ПРАВИЛО ПОСЛЕ REJECT
============================================================

После REJECT сначала называется конкретная ошибка: состав, лицо, костюм, локация, действие, реквизит, сторона улики, свет или формат.

Повтор допускается только после исправления конкретной причины. Нельзя:
— повторять тот же перегруженный запрос;
— добавлять длинный список запретов вместо исправления постановки;
— возвращать удалённых из раскадровки персонажей;
— использовать брак как новый референс.
