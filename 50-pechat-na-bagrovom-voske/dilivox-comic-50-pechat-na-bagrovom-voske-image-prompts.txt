ПРАВИЛО ФОРМИРОВАНИЯ РАБОЧЕГО ПРОМПТА

Для конкретной генерации берётся только один блок текущего кадра из production-storyboard и только его утверждённые PNG из reference-pack-manifest.

В рабочий визуальный запрос не включаются:
— реплики;
— HTML-подписи;
— литературный пересказ;
— альтернативные версии;
— служебные названия;
— номер кадра внутри изображения;
— сведения о будущих кадрах;
— референсы персонажей, которых нет в текущем кадре;
— отклонённые изображения.

ФОРМАТ РЕЗУЛЬТАТА
— один самостоятельный вертикальный кадр 4:5;
— без текста, номера, рамки, коллажа, логотипа и водяного знака;
— исторический кинематографичный реализм Франции 1636 года;
— точное соответствие утверждённым PNG;
— самостоятельная PASS/REJECT-проверка после генерации.
